Mind Map — Layout Approach

Members + Groups as nodes. Which layout fits the vibe?

A — Dagre (auto top-down)

Groups at top, members branch below. Clean, structured, algorithmic. Read-only layout — no dragging. Simple to implement.

B — Force-directed (organic)

Spring simulation — connected nodes cluster together. Draggable. Feels alive. Matches the chaotic-ND brand. More complex to implement.

C — Radial (hub + spokes)

System at center, groups on mid ring, members on outer ring. Very structured, symmetrical. Can feel mechanical for organic systems.

My recommendation: B (force-directed) — matches the brand, clustering gives instant visual signal about group membership, and it's draggable.
